Rejouice®️ Website
Files
index.html: The main HTML file that contains the structure and content of the website.
NBInternationalProBoo.ttf: Custom font used in the website.
Rejouice-Headline.ttf: Custom font used in the website.
script.js: JavaScript file that handles animations, smooth scrolling, and other interactive features.
style.css: CSS file that styles the website.
Dependencies
The project uses the following external libraries:

Swiper: For creating responsive sliders.
Remix Icon: For using icons.
Locomotive Scroll: For smooth scrolling.
GSAP: For animations.
HTML Structure
The HTML file (index.html) includes the following sections:

Loader: A loading screen with the text "Tomorrow's Brands Today".
Upper Parent: A hidden section that appears when the menu is clicked, containing navigation links and a button.
Main Content: The main content of the website, divided into several pages:
Page 1: Contains a video background, a mouse follower, and the main heading.
Page 2: Describes the agency's services and engagement models.
Page 3: Showcases the agency's services with images and videos.
Page 4: Contains a video and SVG animations.
Page 5: A contact section with a Swiper slider.
Footer: The footer with the copyright information.
CSS Styling
The CSS file (style.css) includes styles for:

Custom fonts (NBInternationalProBook.ttf and Rejouice-Headline.ttf).
General styles for the body, HTML, and other elements.
Specific styles for each section of the website, including the loader, pages, and footer.
Swiper slider styles.
JavaScript Functionality
The JavaScript file (script.js) includes:

Locomotive Scroll Initialization: For smooth scrolling.
Mouse Follower: A function that makes an element follow the mouse cursor on the first page.
Swiper Initialization: For creating a responsive slider in the contact section.
GSAP Animations: For animating the loader, text, and other elements on the page.
